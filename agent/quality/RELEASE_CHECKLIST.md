# Release Checklist

- [ ] Milestone acceptance criteria passed.
- [ ] All release-blocking tasks have PASS review reports.
- [ ] No unresolved Critical/High findings.
- [ ] Relevant integration/E2E flows verified.
- [ ] Security/privacy implications reviewed.
- [ ] Migrations/backups/rollback plan verified where applicable.
- [ ] Monitoring/error reporting readiness checked.
- [ ] Accessibility/usability pass for user-facing flows.
- [ ] Dependency/license/runtime environment changes documented.
- [ ] Release notes prepared.
- [ ] Human explicitly approved production release/deployment.
