# Durable Project Memory

`agent/` is the tool-neutral source of truth for AI-assisted development.

- `product/`: what and why
- `design/`: design references and implementation constraints
- `architecture/`: target technical system
- `decisions/`: pending and approved human/architecture decisions
- `discovery/`: observed reality of an existing repository
- `planning/`: roadmap and milestones
- `tasks/`: atomic execution contracts and lifecycle
- `reports/`: implementation, review, and QA evidence
- `quality/`: mandatory gates
- `history/`: durable change history
- `templates/`: schemas agents must follow
